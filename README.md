## 🤖 How I work with AI

I use Claude Code for most of the implementation. My part is deciding what gets built and checking what comes out.

**In my development workflow**

- **Spec-driven development.** Each feature starts with a written plan: requirements, user flows, design, security threats, tests and a step-by-step checklist. Agents implement one step at a time, one commit per step.
- **Context engineering.** Project rules (`AGENTS.md`), 100+ agent skills and system docs live in the repository, so every session starts from the same context.
- **Multi-agent orchestration.** 16 specialized subagents (planning, backend, frontend, tests, security and database review), with the stronger model on planning and a cheaper one on routine checks.
- **MCP servers.** Up-to-date library docs (Context7), browser testing (Playwright) and a code knowledge graph the agents query before exploring the code.
- **Hooks as guardrails.** A pre-tool hook blocks any query that would send our code to an external docs service.
- **Quality gates.** Every commit passes lint, tests and a security and code-smell checklist before I review it.

**In the products I build**

- **Vision LLM extraction.** Stores upload photos of their printed menu or catalog, and a vision model turns them into products ready to review.
- **Structured outputs.** The model answers in a fixed JSON schema, validated before anything is saved.
- **Multi-provider fallback.** One OpenAI-compatible client for Gemini, OpenAI and OpenRouter, with a fallback chain of models, retries, per-call cost tracking and routing to providers that don't keep the data.
